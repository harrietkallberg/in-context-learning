 \section{A review of \citet{garg2022what}}

  \paragraph{Hypothesis.} The paper hypothesises that transformers trained on a function
  class, such as linear functions, sparse linear functions, two-layer neural networks or
  decision trees, encode a non-trivial learning algorithm within a single forward pass.
  Given in-context examples from a function not seen during training, they can then
  predict its value at a new query input. Since ICL is hard to study in LLMs, the paper
  uses a controlled setting with transformers trained from scratch. For linear functions
  $f(x)=w^\top x$, every prompt uses a new $w$, so memorising a single function does not
  work. Instead, the model must infer $w$ from the pairs $\{(x_i, f(x_i))\}_{i=1}^k$ to
  predict $f(x_{\text{query}})$.

  \paragraph{Formulation.} Let $D_\mathcal{X}$ be a distribution over inputs and
  $D_\mathcal{F}$ a distribution over functions in $\mathcal{F}$. A prompt is a sequence
  of pairs followed by a query,
  \begin{equation}
    P = (x_1, y_1, \dots, x_k, y_k, x_{\text{query}}), \qquad y_i = f(x_i),
    \label{prompt}
  \end{equation}
  with $x_i, x_{\text{query}} \sim D_\mathcal{X}$ i.i.d.\ and $f \sim D_\mathcal{F}$.
  A model $M$ \emph{in-context learns} $\mathcal{F}$ up to $\epsilon$ if, for some loss
  $\ell$,
  \begin{equation}
    \mathbb{E}_P\!\left[\ell\big(M(P), f(x_{\text{query}})\big)\right] \le \epsilon.
  \end{equation}

  \paragraph{Training.} A decoder-only GPT-2 style transformer $M$ (12 layers, 8 heads,
  256-dimensional embeddings, 9.5M parameters) is trained from scratch. At each step, a
  function $f$ and inputs $x_i$ are sampled, and the model predicts $f(x_{i+1})$ from every
  prefix $P^i = (x_1, y_1, \dots, x_i, y_i, x_{i+1})$, minimising
  \begin{equation}
    \mathbb{E}_P\!\left[\frac{1}{k+1}\sum_{i=0}^{k}
    \ell\big(M(P^i), f(x_{i+1})\big)\right]
    \label{objective}
  \end{equation}
  with $\ell$ the squared error. In the linear case, which this report focuses on because
  of its simplicity and particularly interesting ICL behaviour,
  $D_\mathcal{X} = \mathcal{N}(0, I_d)$ and $D_\mathcal{F}$ is given by $f(x) = w^\top x$
  with $w \sim \mathcal{N}(0, I_d)$, $d = 20$. Training uses Adam for 500k steps with batch
  size 64. A curriculum that gradually increases the input dimension and prompt length
  speeds up training significantly.

  \paragraph{Evaluation.} The model is evaluated by the squared error normalised by $d$,
  \begin{equation}
    \frac{1}{d}\big(M(P)-f(x_{\text{query}})\big)^2,
    \label{error}
  \end{equation}
  as a function of the number of in-context examples $k$. In the linear case, it is
  compared to minimum-norm least squares (optimal for this noiseless problem), the
  averaging estimator $\hat{w}=\frac1k\sum_i x_i y_i$, and 3-nearest neighbours.

  \paragraph{Results.} The transformer's error tracks that of least squares for every $k$
  and is far below averaging and nearest neighbours. It degrades gracefully under skewed
  input covariance and mismatched context and query, but is less robust to rescaling the
  inputs. It also handles noisy labels and reproduces the double descent curve of least
  squares. The transformer matches Lasso on sparse linear functions and a network trained
  by Adam on the context for two-layer ReLU networks. On depth-4 decision trees it
  outperforms greedy tree learning and XGBoost.
